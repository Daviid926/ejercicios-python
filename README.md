Ejercicios simples para hacer durante una tarde.
Básicos (variables y operaciones)

Pide al usuario su nombre y salúdalo con Hola, <nombre>.
Pide dos números y muestra su suma, resta, multiplicación y división.
Convierte grados Celsius a Fahrenheit (F = C * 9/5 + 32).
Calcula el área de un círculo a partir de su radio.

Condicionales
5. Pide un número y di si es par o impar.
6. Pide la edad y di si la persona es mayor de edad.
7. Pide tres números y muestra el mayor.
8. Pide una nota (0-10) y muestra: suspenso, aprobado, notable o sobresaliente.

Bucles
9. Imprime los números del 1 al 20.
10. Imprime la tabla de multiplicar de un número que elija el usuario.
11. Suma todos los números del 1 al 100.
12. Imprime solo los números pares del 1 al 50.

Cadenas (strings)
13. Pide una palabra y muéstrala al revés.
14. Cuenta cuántas vocales tiene una frase.
15. Comprueba si una palabra es un palíndromo (como "reconocer").

Listas
16. Crea una lista de 5 números y calcula su media.
17. Encuentra el número más grande y el más pequeño de una lista sin usar max() ni min().
18. Elimina los elementos repetidos de una lista.

Funciones
19. Escribe una función es_primo(n) que devuelva True o False.
20. Escribe una función que calcule el factorial de un número.
